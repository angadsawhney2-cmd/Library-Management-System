# Library-Management-System
A menu-driven Library Management System developed in Python as part of a four-person programming project.

The system allows library staff to manage library items and enables members to register, borrow, return and view available items. Data is stored using text files so that library records persist between program sessions.

## Features

- Add, edit and delete library items
- Register and manage library members
- Borrow and return library items
- Track borrowing records
- Save and reload data using text files
- Separate Staff and Member menus
- Input validation and error handling

## Programming Concepts

- Object-Oriented Programming
- Classes and objects
- Inheritance
- Polymorphism
- Encapsulation
- Abstract classes
- File I/O
- Exception handling
- Lists and data processing
